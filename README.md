# SQL Practice Solutions

This repository contains my complete set of solutions to all problems from **[sql-practice.com](https://www.sql-practice.com/)**.
The focus is on writing **clean, readable, and efficient SQL**.
> The solutions are written using **standard ANSI SQL**, with compatibility in mind for
**PostgreSQL**, **MySQL**, and other relational databases where possible.

## Contents

The solutions are organized by SQL concepts, and **each query is tagged with its original
question number and problem statement** for easy reference.

Each query includes:
- the **question number**
- the **original problem description**
- the **SQL solution**

## Database Compatibility

The queries are written using **ANSI-standard SQL** wherever possible.
They are compatible with:

- PostgreSQL
- MySQL
- SQLite (with minor adjustments if required)

> Database-specific features are avoided unless explicitly necessary.

## Database Schema

The schema follows the hospital-style database used by **sql-practice.com**, including tables such as:

- patients
- doctors
- admissions
- provinces

## How to Run
- Run these queries on **[sql-practice.com](https://www.sql-practice.com/)**  

OR (on local if you want to try them on your local computer)
1. Create a database in your preferred SQL engine
2. Load the schema and sample data
3. Execute any solution file using the solutions
